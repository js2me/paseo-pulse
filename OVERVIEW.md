Paseo Pulse adds a Sessions page with a compact project-grouped list. Select a session to open it directly in Paseo. The sidebar badge shows the number of sessions in Attention and updates while the page is closed.

Attention includes running or starting sessions, permission requests, unread errors and replies, and conversations with messages from the last four hours. Sessions opened from this plugin at least three times in seven days also remain in Attention. Rapid repeat clicks within a minute count as one opening. Visit history is stored on the host and shared across connected devices. The SDK does not expose views made elsewhere in Paseo.

Running sessions use a blue spinner; unread replies are green, actions yellow and errors red. Read sessions and replies marked OK are muted gray. OK clears the specific reply or error, while recent or frequently opened sessions remain listed. New replies regain their attention indicators. Marks are stored on the host and synchronized between clients.

All shows six recent sessions per project; More reveals the rest. Rows show the session title, a short reply preview and the actual time of the last message. Reading a session does not change its message timestamp. Search covers titles, projects, workspaces, providers and paths. Project headers use Paseo logos and offer a + button to create a session in that project. The global + opens the same form with a project and agent/profile selector. Created sessions open in Paseo.

The interface follows Paseo’s language setting: English, Russian, French or Traditional Chinese. Chinese app locales, including Paseo’s current zh-CN option, use Traditional characters; zh-TW and zh-Hant are also supported. Other languages fall back to English. Language changes apply without reloading or clearing search, expanded groups or the creation form. User-provided project/session names, provider details and conversation content are not translated.

Requires Paseo 0.15.0 or later. The plugin loads the complete non-archived, non-internal session directory in pages, without a 200-session limit. Status updates use the existing host connection. A cached read-only index of saved provider transcripts updates previews every five seconds without starting agents or fetching full provider histories. No external services are used. Previously saved drafts, queued messages and attachments remain on the host and are no longer processed by the plugin.
