Paseo Pulse adds a Pulse page with a compact project-grouped list. Select a session to open it directly in Paseo. Two sidebar badges update while the page is closed: blue counts running or starting sessions, and green counts new completed replies. Read, recent and frequently viewed sessions do not increase the green badge.

Grouping defaults to By workspace. Select None in the toolbar to show one list without project headers or preview limits; search and Attention/All filters still apply. Attention priority and pinned-first ordering in All apply across projects in this mode. Select By status to split sessions into Needs action (permissions and errors), In progress, Reply ready (unread replies), and Other. Empty groups are omitted, and status changes move sessions between groups automatically.

When saved usage is available, each row shows an approximate session token total below the time. It includes processed input and output, cache and reasoning without counting subtotals twice, and is not a monetary cost or the current context size. Codex uses its cumulative total; OpenCode sums saved assistant usage. Claude totals are shown only when the complete transcript fits the bounded 1 MiB read, with repeated message snapshots deduplicated. Unavailable or unreliable totals are omitted. Reads reuse the existing cached index and never start agents.

The list uses the full available width. Custom names and pins from the native Paseo sidebar update live. In All, pinned sessions appear first within each project and count toward the six visible rows; Attention keeps its existing priority order. Title, preview and time contrast reflect message age, with separate levels for minutes, hours and days. Read sessions remain subdued while retaining these age differences. Active states keep their blue, green, yellow or red accents; pins emphasize names without making old message timestamps look fresh.

Attention includes running or starting sessions, permission requests, unread errors and replies, and conversations with messages from the last four hours. Sessions opened from this plugin at least three times in 24 hours also remain visible in Attention. Sessions opened at least four times in seven days appear under More within each project unless another attention reason already makes them visible. Search reveals matching hidden sessions. Attention groups default to collapsed when every session has a known last message older than ten hours, unless work is running or permission is pending. You can reopen them manually; search expands matching groups. Rapid repeat clicks within a minute count as one opening. Visit history is stored on the host and shared across connected devices. The SDK does not expose views made elsewhere in Paseo.

Running sessions use a blue spinner; unread replies are green, actions yellow and errors red. Read sessions and replies marked OK are muted gray. OK clears the specific reply or error, while recent or frequently opened sessions remain listed. New replies regain their attention indicators. Marks are stored on the host and synchronized between clients.

All shows six recent sessions per project; More reveals the rest. Rows show the session title, a short reply preview and the actual time of the last message. Reading a session does not change its message timestamp. Search covers titles, projects, workspaces, providers and paths. Project headers use Paseo logos. Their + button opens Paseo’s native New workspace screen with that project selected. The global + opens the same screen for the selected host. No workspace or agent is created until you submit the native form. This requires a Paseo client with the plugin New workspace navigation capability; older clients show an update notice.

The interface follows Paseo’s language setting: English, Russian, French or Traditional Chinese. Chinese app locales, including Paseo’s current zh-CN option, use Traditional characters; zh-TW and zh-Hant are also supported. Other languages fall back to English. Language changes apply without reloading or clearing search or expanded groups. User-provided project/session names, provider details and conversation content are not translated.

Requires Paseo 0.15.0 or later. The plugin loads the complete non-archived, non-internal session directory in pages, without a 200-session limit. Status updates use the existing host connection. A cached read-only index of saved provider transcripts updates previews every five seconds without starting agents or fetching full provider histories. No external services are used. Previously saved drafts, queued messages and attachments remain on the host and are no longer processed by the plugin.
